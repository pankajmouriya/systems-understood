**Local Storage:** (Persistent)

- Can be shared between windows with Same Origin
- Remains even after browser window is closed

**Session Storage:** (Non-Persistent)

- Applies to Active window
- Destroyed after windows is closed


Web Storage follows the same rule of Same Origin Policy. Lets see it in action

Steps:
1. Open Developer Tools
2. Storage
3. Under Local Storage, add Key and Value as shown below. You can also do it via console

<Figure src="/img/docs/appsec/sop/localstorage1.png" alt="Same Origin Policy to Web Storage, figure 1" width={1018} height={308} />

```js
window.localStorage["Token-key-Name"] = "Token-Value"
```

4. Navigate to Browser Console
```js
window.localStorage
```

<Figure src="/img/docs/appsec/sop/localstorage2.png" alt="Same Origin Policy to Web Storage, figure 2" width={1109} height={298} />
